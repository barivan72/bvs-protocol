# BVS Protocol icon/install final fix

The production manifest must use raster PNG icons (192x192 and 512x512), not only SVG, for reliable Windows/Edge/PWA shortcut rendering. The final logo is round, blue/silver/white, with B/V/S 3D spheres and BVS PROTOCOL text. Hero B/V/S spheres move on atom orbits while the letters stay upright. Stage selectors and in-app icon language use matching 3D spherical depth, highlights and shadows.
